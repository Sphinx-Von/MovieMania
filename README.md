# 🎬 MovieMate - Your Personal Movie Tracker

MovieMania is a sleek React + Vite application that allows you to search for movies and build your own favorites collection — all in a smooth, modern UI.

## 🚀 Features

- 🔍 **Search Movies** – Instantly search for your favorite films using **The Movie DB API**
- ❤️ **Add to Favorites** – Click the **"Favorite"** button to save movies to your personal list
- 🏠 **Home Page** – Browse movies displayed as elegant cards
- ⭐ **Favorites Page** – View and manage your saved favorite movies

## 🔧 Tech Stack

- ⚡ React + Vite
- 📡 The Movie DB API
- 🎨 CSS Modules or Tailwind CSS (if used)
- 🔁 React Hooks (`useState`, `useEffect`)
- 📂 Local state or context (if used for favorites)

```bash

cd moviemate

🌐 API Setup

    Sign up at The Movie DB

    Get your API key

# 2. Install dependencies
